# DUPB Multi-Class Explorer

Interface web para consulta ao **Dicionário de usos do português do Brasil** (Francisco S. Borba, Ática, 2002).

## Release 1

- Entradas de consulta: **20.736**
- Acepções: **37.975**
- Predicadoras: **2.979**
- Não predicadoras: **34.996**
